# Watermark-Remover · 净痕

去水印工具。一款完全在浏览器本地运行的图片水印区域修复工具。上传图片后，用画笔覆盖需要清除的区域，工具会根据周围像素进行填充和融合。

在线使用：<https://132564-n.github.io/Watermark-Remover/>

## 运行

无需安装依赖。直接用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 当前能力

- 支持 JPG、PNG、WebP（最大 20 MB）
- 涂抹与擦除选区
- 点击一处水印，自动识别并标记画面中的相似字码
- 点击虚线标识可取消或恢复单处水印选择
- 撤销、重做和缩放
- 本地像素修复及原图对比
- AI 内容修复：重建人物、纹理和复杂结构
- 重复透明文字/Logo 使用多实例一致性蒙版与局部纹理匹配，不加载大模型
- 识别结果过滤低相似度候选，减少误选和错位修复
- AI 组件加载或推理失败时自动回退到轻量修复，避免页面直接中断
- 超宽画笔智能收窄：保留水印两侧的原始纹理，并羽化修复边缘
- 快速填充：处理纯色、天空和渐变背景
- 导出 PNG
- 无上传、无追踪、无第三方依赖

AI 内容修复由 [LaMa](https://github.com/advimman/lama) 驱动，并通过仓库内置的 ONNX Runtime Web 在浏览器本机运行。第一次使用 AI 模式时会加载约 62 MB 的 INT8 模型和约 22 MB 的推理组件，之后浏览器可复用缓存；图片数据不会发送给模型服务器。

被完全遮挡的原始像素无法精确恢复，AI 模式会结合周围内容生成视觉上合理的结果。默认画笔已调整为 30 px；请沿水印轮廓完整涂抹并多覆盖 2–3 像素，画笔越贴近水印，保留的原图细节越多。

同一水印重复出现时，选择左侧“识别”工具，再点击一处完整水印的中心。网页会以虚线框标出相似字码，并用多处实例的共同特征生成精细字形蒙版；再次点击某个虚线框可取消或恢复该处选择。识别到的重复水印会优先使用轻量局部纹理匹配，避免加载大模型造成的等待或内存压力。识别和修复完全在浏览器本机完成。

细小文字、Logo 和半透明重复水印优先使用“识别”；单个小遮挡可用画笔配合“快速”；遮住人物或复杂物体的大块不透明水印则用画笔配合“AI”。隐形水印需要针对具体算法、密钥或检测器处理，本工具不承诺通用识别或去除。

一张图片有多个分散水印时，可以逐个修复。完成一处后直接涂抹下一处，网页会保留上一处结果并继续处理。

## 测试

安装开发依赖后运行端到端回归测试：

```powershell
npm install
npm test
```

测试会在真实浏览器中完成上传、相似水印识别、误选过滤、虚线框切换、重复透明水印、涂抹、快速修复、AI 修复、AI 故障回退、撤销和 PNG 导出，并量化简单背景、复杂纹理和多处分散水印的清除效果与细节保留率。

水印形式、方法选择和浏览器端工程约束的调研见 [`docs/watermark-removal-research.md`](docs/watermark-removal-research.md)。

仅用于处理你拥有或获得授权的素材。LaMa ONNX 模型由 `g-ronimo/lama` 以 Apache-2.0 许可提供。
