# Watermark-Remover · 净痕

去水印工具。一款完全在浏览器本地运行的图片水印区域修复工具。上传图片后，用画笔覆盖需要清除的区域，工具会根据周围像素进行填充和融合。

在线使用：<https://132564-n.github.io/Watermark-Remover/>

## 运行

无需安装依赖。直接用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 当前能力

- 支持 JPG、PNG、WebP（最大 20 MB）
- 涂抹与擦除选区
- 撤销、重做和缩放
- 本地像素修复及原图对比
- AI 内容修复：重建人物、纹理和复杂结构
- 快速填充：处理纯色、天空和渐变背景
- 导出 PNG
- 无上传、无追踪、无第三方依赖

AI 内容修复由 [LaMa](https://github.com/advimman/lama) 驱动，并通过 ONNX Runtime Web 在浏览器本机运行。第一次使用 AI 模式时需要下载约 62 MB 的 INT8 模型，之后浏览器可复用缓存；图片数据不会发送给模型服务器。

被完全遮挡的原始像素无法精确恢复，AI 模式会结合周围内容生成视觉上合理的结果。请沿水印轮廓完整涂抹并多覆盖 2–3 像素，避免把希望保留的内容也涂入选区。

一张图片有多个分散水印时，可以逐个修复。完成一处后直接涂抹下一处，网页会保留上一处结果并继续处理。

## 测试

安装开发依赖后运行端到端回归测试：

```powershell
npm install
npm test
```

测试会在真实浏览器中完成上传、涂抹、快速修复、AI 修复、撤销和 PNG 导出，并量化简单背景与复杂结构的清除效果。

仅用于处理你拥有或获得授权的素材。LaMa ONNX 模型由 `g-ronimo/lama` 以 Apache-2.0 许可提供。
