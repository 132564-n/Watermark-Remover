# Watermark-Remover · 净痕

去水印工具。一款完全在浏览器本地运行的图片水印区域修复工具。上传图片后，用画笔覆盖需要清除的区域，工具会根据周围像素进行填充和融合。

在线使用：<https://132564-n.github.io/Watermark-Remover/>

## 运行

无需安装依赖。直接用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 当前能力

- 支持 JPG、PNG、WebP（最大 20 MB）
- 涂抹与擦除选区
- 撤销、重做和缩放
- 本地像素修复及原图对比
- 导出 PNG
- 无上传、无追踪、无第三方依赖

## 测试

安装开发依赖后运行端到端回归测试：

```powershell
npm install
npm test
```

测试会在真实浏览器中完成上传、涂抹、修复、撤销和 PNG 导出，并量化中心与角落水印的清除效果。

仅用于处理你拥有或获得授权的素材。当前算法适合纯色、渐变和弱纹理背景；复杂纹理、大面积人物遮挡建议使用服务端 AI 修复模型。
